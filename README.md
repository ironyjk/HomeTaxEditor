# 홈택스 자동 공제 반영 도구 - POC

## 개요

이 프로젝트는 홈택스(국세청 세금 신고 시스템)의 웹페이지에서 DOM(Document Object Model)을 읽고 수정할 수 있는지를 검증하는 POC(Proof of Concept) 프로그램입니다.

C# WinForms와 WebView2를 사용하여 홈택스 웹페이지를 내장 브라우저에서 로드하고, JavaScript를 통해 DOM을 조작합니다.

## 주요 기능

- **WebView2 기반 내장 브라우저**: Edge 기반의 최신 브라우저 엔진 사용
- **홈택스 접속**: 사용자가 직접 로그인할 수 있는 환경 제공
- **DOM 읽기**: 웹페이지의 테이블 정보, 행 개수, 텍스트 내용 읽기
- **DOM 수정**: 테이블 행의 스타일 변경, 체크박스/라디오 버튼 상태 변경
- **C# ↔ JavaScript 통신**: WebView2의 postMessage를 통한 양방향 통신

## 기술 스택

- **언어**: C# (.NET 8.0)
- **UI 프레임워크**: Windows Forms
- **웹 브라우저**: Microsoft Edge WebView2
- **대상 플랫폼**: Windows

## 요구사항

- Windows 10 이상
- .NET 8.0 SDK
- Microsoft Edge WebView2 Runtime (자동 설치됨)

또는 Visual Studio에서 프로젝트를 열어서 실행할 수 있습니다.

## 사용 방법

### 1. 프로그램 시작

프로그램을 실행하면 다음과 같은 화면이 표시됩니다:
- 상단: 컨트롤 버튼 영역 (홈택스 접속, DOM 테스트 실행)
- 중앙: WebView2 브라우저 영역
- 하단: 로그 메시지 표시 영역

### 2. 홈택스 접속

1. "홈택스 접속" 버튼을 클릭합니다.
2. WebView2에 홈택스 메인 페이지가 로드됩니다.
3. 사용자가 직접 로그인을 수행합니다:
   - 아이디/비밀번호 입력
   - 공동인증서 선택 및 비밀번호 입력
4. 로그인 후 원하는 메뉴로 이동합니다 (예: 사업용 신용카드 사용내역).

### 3. DOM 테스트 실행

1. 테이블이 있는 페이지로 이동합니다.
2. "DOM 테스트 실행" 버튼을 클릭합니다.
3. 프로그램이 다음 작업을 수행합니다:
   - **DOM 읽기**:
     - 페이지에서 가장 큰 테이블을 찾습니다.
     - 테이블의 행 개수를 세어 로그에 표시합니다.
     - 첫 번째 행의 텍스트 내용을 읽어 로그에 표시합니다.
   - **DOM 수정**:
     - 첫 번째 행의 배경색을 노란색(#FFFF99)으로 변경합니다.
     - 첫 번째 행에 주황색 테두리(#FF6600)를 추가합니다.
     - 체크박스가 있으면 상태를 토글합니다.
     - 라디오 버튼이 있으면 선택합니다.
4. 하단 로그 영역에서 결과를 확인합니다.

### 4. 로그 확인

하단의 로그 영역에서 다음 정보를 확인할 수 있습니다:
- WebView2 초기화 상태
- 페이지 로드 완료/실패
- DOM 테스트 결과 (행 개수, 첫 번째 행 텍스트, 수정 성공 여부)
- 에러 메시지

## 주요 코드 설명

### Form1.cs

주요 메서드:
- `InitializeWebView2()`: WebView2 초기화 및 이벤트 핸들러 등록
- `btnConnectHomeTax_Click()`: 홈택스 페이지 로드
- `btnTestDOM_Click()`: DOM 읽기/수정 JavaScript 실행
- `CoreWebView2_WebMessageReceived()`: JavaScript로부터 메시지 수신
- `LogMessage()`: 로그 메시지 표시

### JavaScript 로직

DOM 테스트 JavaScript는 다음을 수행합니다:
1. 페이지의 모든 테이블을 찾아 가장 큰 테이블 선택
2. 테이블 행 개수 카운트
3. 첫 번째 행의 텍스트 추출
4. 첫 번째 행의 스타일 수정
5. 체크박스/라디오 버튼 찾아서 상태 변경
6. 결과를 JSON으로 직렬화하여 C#으로 전송

## POC 성공 기준

다음 조건이 모두 만족되면 POC 성공으로 판단합니다:

- ✅ WebView2를 통해 홈택스 로그인 페이지 정상 로딩
- ✅ 사용자가 WebView2 안에서 공동인증서 로그인 완료 가능
- ✅ C#에서 버튼 클릭으로 JavaScript 실행 가능
- ✅ JavaScript가 DOM을 탐색하여 테이블 정보를 읽어 C#에 전달
- ✅ DOM 요소(행 배경색, 체크박스 등)가 실제로 변경되는 것을 육안으로 확인
- ✅ 에러 상황에 대한 로그 메시지 제공

## 제약사항 및 알려진 이슈

### 홈택스 UI 변경
홈택스가 HTML 구조를 변경하면 DOM 선택자가 작동하지 않을 수 있습니다. 현재 코드는 일반적인 `table`, `tr`, `td` 태그를 기반으로 작동하므로 비교적 유연합니다.

### 보안 정책
홈택스의 CSP(Content Security Policy) 설정에 따라 JavaScript 실행이 제한될 수 있습니다. WebView2의 `ExecuteScriptAsync`는 대부분의 경우 정상 작동합니다.

### 공동인증서 호환성
WebView2가 Edge 기반이므로 대부분의 공동인증서 모듈과 호환됩니다. 만약 문제가 발생하면 Edge 브라우저에서 먼저 홈택스 로그인을 테스트해보세요.

### WindowsBase 경고
빌드 시 WindowsBase 버전 충돌 경고가 발생할 수 있으나, 실행에는 문제가 없습니다.
