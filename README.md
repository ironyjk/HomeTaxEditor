# 홈택스 사업용 신용카드 매입세액 공제 자동 반영 도구

부가가치세 신고 시, **사업용 신용카드 매입내역의 공제/불공제 여부를 홈택스에서 한 건씩 바꾸는 반복 작업**을 자동화하는 Windows 데스크톱 도구입니다.

엑셀로 미리 정리한 "건별 공제/불공제 결정"을 홈택스 **[매입세액 공제 확인/변경]** 화면에 자동으로 반영합니다. WebView2(Edge 엔진) 내장 브라우저에 사용자가 직접 공동인증서로 로그인하면, 프로그램이 화면의 표를 페이지마다 읽어 엑셀과 매칭한 뒤 공제/불공제를 바꾸고 저장합니다.

> ⚠️ 이 도구는 **디와이산업개발(주)의 최희철이 자사 부가세 업무를 위해 만든 유틸리티**를, 같은 불편을 겪는 사업자·실무자에게 도움이 되도록 **공익 목적으로 공개**한 것입니다. 개발자는 **세무 전문가(세무사)가 아니며**, 국세청/홈택스와 무관한 비공식 도구입니다. 세무 판단과 신고 결과에 대한 책임은 지지 않으니, 아래 [면책·주의사항](#️-면책주의사항)을 반드시 읽고 사용하세요.

## 다운로드

받아서 압축을 풀고 `HomeTaxEditor.exe` 를 실행하면 됩니다. 둘 중 하나를 선택하세요.

- **[⬇️ 설치 불필요 버전 (standalone, 약 77MB)](https://github.com/ironyjk/HomeTaxEditor/releases/download/v1.0.0/HomeTaxEditor-v1.0.0-win-x64-standalone.zip)** — 런타임이 내장되어 **설치 없이 바로 실행**됩니다. IT에 익숙하지 않다면 이걸 받으세요.
- **[⬇️ 가벼운 버전 (lite, 약 11MB)](https://github.com/ironyjk/HomeTaxEditor/releases/download/v1.0.0/HomeTaxEditor-v1.0.0-win-x64-lite.zip)** — 용량이 작지만 실행에 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)이 필요합니다.

> 최신 버전·전체 목록은 [릴리스 페이지](https://github.com/ironyjk/HomeTaxEditor/releases/latest)에서 확인하세요.

## 처음 실행할 때 보안 경고가 뜨면 (정상입니다)

이 도구는 **코드 서명 인증서가 없는 무료 공개 프로그램**이라, 처음 실행하면 윈도우가 경고를 띄웁니다. 바이러스라서가 아니라 "인증서로 제작자를 확인할 수 없다"는 뜻입니다. (소스가 전부 공개되어 있으니 직접 확인·빌드할 수도 있습니다.)

**1) 압축을 풀기 전에 zip 차단 해제 (권장)**
1. 받은 `.zip` 파일을 **우클릭 → 속성**.
2. 하단에 **"차단 해제(Unblock)"** 체크박스가 있으면 체크 → **확인**.
3. 그런 다음 압축을 풉니다. (이러면 아래 SmartScreen 경고가 안 뜨는 경우가 많습니다.)

**2) "Windows의 PC 보호" (SmartScreen) 창이 뜨면**
- **"추가 정보"** 클릭 → 나타나는 **"실행"** 버튼을 누릅니다.

**3) "게시자를 확인할 수 없습니다 / 알 수 없는 게시자" 창이 뜨면**
- **"실행"** 을 누릅니다.

> 백신(안티바이러스)이 막는 경우, 해당 폴더를 예외로 추가하거나 소스에서 직접 빌드해서 사용하세요. 코드 서명 인증서를 적용하면 이 경고가 사라지지만, 무료 공개 도구라 서명은 적용하지 않았습니다.

## 무엇을 해결하나

홈택스에 사업용 신용카드를 등록하면 카드 사용내역이 자동으로 올라오지만, 공제/불공제 초기 분류가 실제와 다른 경우가 많습니다(비영업용 승용차 주유, 접대성 경비, 후불하이패스 등). 건수가 수백~수천 건이면 홈택스 화면에서 한 줄씩 바꾸는 게 큰 부담입니다.

이 도구는 그 결정을 **엑셀에서 정리 → 홈택스에 일괄 자동 반영**합니다.

## 주요 기능

- **WebView2 내장 브라우저 + 직접 로그인**: 인증서/아이디는 프로그램이 저장하지 않으며, 사용자가 홈택스에 직접 로그인합니다.
- **엑셀 → 홈택스 자동 매칭**: `승인일자 + 가맹점사업자번호 + 합계` 세 가지로 웹 화면의 각 행을 엑셀과 매칭합니다.
- **분기 자동 판별·전 페이지 순회**: 엑셀에 여러 분기가 섞여 있어도 포함된 모든 (연도·분기)를 각각 조회하고, 페이지네이션을 끝까지 넘기며 처리합니다.
- **간이과세자 자동 제외**: 공제여부를 바꿀 수 없는 간이과세 거래는 건너뜁니다.
- **순서 기반(하이브리드) 매칭**: 같은 날짜·거래처·금액이 여러 건이면(대표적으로 후불하이패스) 카드번호가 웹 화면에 안 보여 값만으로는 구분이 안 됩니다. 이때는 **엑셀 파일 순서 = 홈택스 조회 순서**로 보고 1:1 배정합니다.
- **⚠️확인요망 표시**: 위처럼 같은 키인데 공제/불공제가 갈리는 그룹은 자동 판정이 100% 확실하지 않으므로 **[변경 내역] 탭에 "확인요망"으로 표시**해, 사람이 눈으로 검증할 수 있게 합니다.
- **변경 내역 확인·CSV 내보내기**: 무엇을 어떻게 바꿨는지 표로 보여주고 파일로 내보낼 수 있습니다.

## 기술 스택

- C# / .NET 8.0 (`net8.0-windows`), Windows Forms
- Microsoft Edge WebView2 (`ExecuteScriptAsync`로 DOM 조작)
- 엑셀 읽기: NPOI(.xls) / EPPlus(.xlsx)
- 테스트: xUnit

## 요구사항

- Windows 10 이상
- **.NET 8.0 Desktop Runtime** — 윈도우에 기본 설치되어 있지 않습니다(구형 .NET Framework와 다른 계열). 없으면 exe 실행 시 설치 안내가 뜹니다.
  - 다운로드: https://dotnet.microsoft.com/download/dotnet/8.0 → **".NET Desktop Runtime 8.0"** 의 **Windows x64** 설치본을 받으세요. (그냥 "Runtime"이 아니라 반드시 **Desktop Runtime**)
- Microsoft Edge WebView2 Runtime (대개 최신 Windows에 기본 설치됨)

> 💡 런타임 설치가 번거롭다면 위 [다운로드](#다운로드)의 **설치 불필요(standalone)** 버전을 받으세요. 런타임이 내장되어 바로 실행됩니다(용량만 큽니다).

## 사용 방법

### 준비 — 엑셀 만들기

홈택스에서 **[부가가치세] → 사업용 신용카드 매입내역**을 엑셀로 내려받은 뒤, 각 행에 대해 공제/불공제 결정을 채워 넣습니다. 프로그램이 사용하는 컬럼은 다음과 같습니다.

| 컬럼 | 설명 |
|------|------|
| 승인일자 | 예: `2026-06-30` |
| 카드번호 | 같은 날짜·금액이 겹칠 때 사람이 구분하는 용도(웹에는 안 보임) |
| 가맹점사업자번호 | 예: `123-45-67890` |
| 합계 | 거래 금액 |
| 공제여부결정 | `공제` 또는 `불공제` |

> 💡 **팁**: 엑셀은 **홈택스 조회 순서와 같은 순서**로 정리하는 걸 권장합니다. 같은 날짜·거래처·금액이 여러 건일 때(후불하이패스 등) 순서대로 매칭되기 때문입니다.

### 1. 프로그램 실행 & 홈택스 로그인

1. 프로그램을 실행합니다.
2. 내장 브라우저에 뜬 홈택스에서 **직접 공동인증서로 로그인**합니다.
3. 반드시 **[부가가치세 → 매입세액 공제 확인/변경]** 화면까지 들어가 둘 필요는 없습니다. 프로그램이 시작 시 해당 메뉴로 자동 진입합니다.

### 2. 엑셀 업로드 및 시작

1. **[엑셀 업로드 및 시작]** 버튼을 누르고 준비한 엑셀 파일을 선택합니다.
2. 프로그램이 자동으로:
   - 매입세액 공제 확인/변경 메뉴로 진입하고,
   - 엑셀을 읽어 포함된 분기를 판별한 뒤,
   - 분기별로 전 페이지를 넘기며 각 행을 매칭하고 공제/불공제를 바꾼 후 **[변경하기]로 저장**합니다.
3. 진행률 바와 **[로그]** 탭에서 실시간 상태를 볼 수 있습니다.
4. 중간에 멈추려면 **[중단]** 버튼을 누릅니다.

### 3. 변경 내역 확인

- **[변경 내역]** 탭에서 날짜·가맹점·금액·변경 전/후·상태를 표로 확인합니다.
- 상태가 **"⚠️확인요망(카드상이)"** 인 행은 같은 날짜·거래처·금액이 공제/불공제로 갈리는 그룹입니다. **저장 후 반드시 눈으로 검증**하세요.
- **[Excel로 다운로드]** 로 변경 내역을 CSV로 내보낼 수 있습니다.

## ⚠️ 면책·주의사항

- **개발자는 세무 전문가(세무사)가 아닙니다.** 이 도구는 공제/불공제를 판단하지 않으며, "사용자가 스스로 정한 결정"을 화면에 옮겨줄 뿐입니다. 세무 판단과 신고 결과의 책임은 전적으로 사용자에게 있습니다.
- **국세청/홈택스와 무관한 비공식 개인 도구**입니다. 국세청은 이 도구를 지원하거나 보증하지 않습니다.
- **세금 계산·공제 판단의 책임은 전적으로 사용자에게 있습니다.** 이 도구는 "사용자가 엑셀에 미리 정한 결정"을 화면에 옮겨줄 뿐, 어떤 거래를 공제/불공제해야 하는지는 판단하지 않습니다.
- **홈택스에 실제 데이터를 저장(변경)합니다.** 반드시 [변경 내역]을 검토하고, **신고 전에 홈택스 화면에서 결과를 직접 확인**하세요. 특히 "확인요망" 표시 건은 사람이 검증해야 합니다.
- **홈택스 화면(HTML/DOM) 구조에 의존**합니다. 국세청이 화면을 개편하면 동작하지 않을 수 있으며, 그 경우 코드 수정이 필요합니다.
- **소프트웨어는 "있는 그대로(AS IS)" 제공**되며 어떤 보증도 하지 않습니다(MIT 라이선스). 사용으로 인한 결과에 대해 저작자는 책임지지 않습니다.
- 인증서·아이디·비밀번호를 저장하거나 외부로 전송하지 않습니다. 로그인은 사용자가 내장 브라우저에서 직접 수행합니다.
